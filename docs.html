01Getting Started

Create a free account, generate an API key from your dashboard, and you're ready to make your first request — no credit card required.

  1. 1
    Sign up for a free account.
  2. 2
    Generate an API key from your dashboard.
  3. 3
    Make a request to any endpoint using your key.

02Authentication

Every request is authenticated with an API key, passed as a header. Keys are scoped per project and can be rotated at any time from your dashboard.

Terminal bash 
# Pass your key on every request-H "x-api-key: rm_live_YOUR_API_KEY"

03Making Requests

All endpoints accept standard query parameters and return JSON. Base URL: https://rapidmap-api.onrender.com

04Endpoints

See the full endpoint reference — geocoding, reverse geocoding, static tiles, and places — on the Maps API page.

05Error Handling

Errors return a standard JSON body with an HTTP status code, an error code, and a human-readable message to help you debug quickly.

06Rate Limits

Rate limits vary by plan. Free tier accounts include 2,500 requests per month; higher tiers raise this ceiling. Current usage is visible from your dashboard at all times.

07SDKs & Libraries

Official SDKs are on the roadmap. Until then, any standard HTTP client works — the API returns plain JSON over REST.
