01Available Endpoints

The API surface mirrors what you already expect from a mapping provider, so migrating rarely takes more than swapping a base URL.

Geocoding

Convert addresses into geographic coordinates via a standard JSON response.

Reverse Geocoding

Turn coordinates back into a human-readable address, worldwide.

Static Map Tiles

Render lightweight static map images for emails, PDFs, or low-bandwidth views.

Places Search

Look up points of interest by name or category near a given location.

02Quick Start

Getting your first request out the door takes three steps and no credit card.

  1. 1
    Create an account — no credit card required to get started.
  2. 2
    Generate an API key — instantly, from your dashboard.
  3. 3
    Send your first request — using the standard cURL call below.
Terminal bash 
curl https://rapidmap-api.onrender.com/v1/geocode \  -H "x-api-key: rm_live_YOUR_API_KEY" \  --data-urlencode "address=1600 Amphitheatre Pkwy"
